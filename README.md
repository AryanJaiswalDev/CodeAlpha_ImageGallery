# CodeAlpha Image Gallery

A responsive image gallery with category filters, lightbox navigation,
image filter effects and image upload.

**Live demo:** https://codealphaimagegallery-nine.vercel.app

## Features
- Responsive grid layout
- Category filters
- Lightbox with next/prev, keyboard and swipe support
- Image filter effects (Grayscale, Sepia, Warm, Cool, Blur)
- Upload your own images

## Tech
HTML, CSS, JavaScript
